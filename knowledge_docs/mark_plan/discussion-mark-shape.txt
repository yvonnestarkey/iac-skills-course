Mark plan shape (for the diagnostic engine)

A typical IAC discussion / application part is weighted toward using the facts:
- Identify the issue from the required (small).
- State the relevant principle or rule (Tier 1 / knowledge).
- Apply that principle to the specific facts, with a consequence or conclusion (Tier 2 / application).

Calculation parts still split the same way: method and principle are knowledge; using the scenario numbers, labelling workings, and concluding in the required format are application.

If a student earns most of the knowledge line items but little of the "apply to X" line items, the script is a conversion problem, not a syllabus gap.

How suggested solutions award marks
- One mark is usually one applied point: principle + this entity's facts + effect/assertion/conclusion.
- Communication / layout marks sit on the required format (memo, report, journal, SOFP extract).
- Workings marks need a visible, cross-referenced computation in ink. A correct total with no working often scores nothing.
- Shopping-list theory, unapplied definitions, and restated scenario facts do not convert.
