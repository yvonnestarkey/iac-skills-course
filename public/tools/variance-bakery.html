The formulas you learnt

Each formula is just the gap between two columns

VarianceFormulaOn the staircase
PriceAQ × (SP − AP)A to B. Same actual quantity, only the price changes.
Mix(Actual total in standard mix − AQ) × SP, per ingredientB to C. Same actual total, only the proportions change.
Yield(SQ for actual output − actual total in standard mix) × SP, or (standard output from actual input − actual output) × standard cost per unitC to D. Same standard mix and prices, only the output changes.

Don't rely on the sign. Ask which side is bigger: if the column nearer actual costs more than the column nearer standard, it's adverse.

The question each variance asks

VarianceThe questionWhere to look in the case
PriceDid we pay more or less per unit than the standard price?New supplier, market price change, bulk discounts, rush orders, an out-of-date standard cost card
MixDid we use the inputs in the standard proportions?Machine calibration, substituted ingredients, operator error, shortages
YieldDid we get the standard output from the actual input?Waste, spoilage, poor-quality inputs, process faults, losses found late
